# 台南市不動產分析 — 使用說明書

**線上網址**：https://tainan-realestate-ai.vercel.app

**資料範圍**：民國 110 年至今的實價登錄交易（每頁最新月份見導覽列右上「最新 XXX 年 X 月」）

> 說明體例：每項功能以 30 字內說明「它做什麼」。

---

## 一、全站共用

| 功能 | 說明（30 字內） |
|------|------|
| 導覽列 | 六個分頁切換，右上顯示資料更新到民國幾年幾月 |
| 篩選列 | 設定日期區間、行政區、建物型態、房型、成/預售、屋齡 |
| 日期區間 | 以民國年月選起訖，預設 114/1～115/6 |
| 行政區多選 | 從 37 個行政區勾選，不選代表全市 |
| 成屋／預售切換 | 預設只看預售屋，可切成屋或兩者合看 |
| 已套用標籤 | 條件以標籤列出，點 × 即可單獨移除該條件 |
| 套用按鈕 | 數據看板需按套用；地圖與框選分析改動即生效 |
| 網址分享 | 篩選條件寫進網址，複製連結給別人會看到同畫面 |
| 主題切換 | 右上「明／暗」鈕，切換亮色或深色介面 |
| 字級切換 | 右上「小／中／大」鈕，大字級適合簡報投影 |

## 二、數據看板（首頁 `/`）

分為「數據看板／地圖／框選分析」三個分頁，離開後會記住上次停留的分頁。

### 2-1 數據看板分頁

| 功能 | 說明（30 字內） |
|------|------|
| KPI 卡片 | 五張卡：成交戶數、均單價、均坪數、均總價、總銷售額 |
| 補登警示 | 迄月太近時提示最近兩個月仍在補登，戶數會低估 |
| 實價登錄明細 | 逐筆交易表，含日期、樓層、坪數、單價、總價、註記 |
| 交易註記 | 標示特殊關係交易、增建、含車位，判讀價格是否失真 |
| 載入更多 | 明細表預設載入一頁，按鈕可續抓後續交易 |
| 個案排行 | 依建案／地址彙總，含銷售戶數、銷售成數、單價區間 |
| 點列開詳情 | 點任一列開右側面板，看該案完整銷售期交易明細 |
| 詳情展開列 | 再點單筆可展開棟號、格局、面積細項、車位、土地 |
| 統計總覽 | 可收合區塊，含行政區排行、類型統計、房型統計三表 |
| 表格排序分頁 | 各統計表可點欄位排序，並以長條顯示數值相對大小 |

### 2-2 地圖分頁

| 功能 | 說明（30 字內） |
|------|------|
| 標記模式 | 群集標記顯示預售與成屋位置，顏色代表單價高低 |
| 熱力圖模式 | 預售屋依自身單價畫藍→黃→紅色塊，看價格帶分布 |
| 單價標籤 | 地圖拉近後在色塊中心顯示該案單價數字 |
| 標記彈窗 | 顯示均單價、均總價、戶數、銷售成數、最新成交月 |
| 查看交易明細 | 彈窗內按鈕開啟該建案的完整交易明細面板 |
| 快速切換 | 地圖上方一鍵切換預售屋／成屋／全部 |
| 圖例 | 左下角說明目前單價色階範圍與成屋標記顏色 |
| 建案棟數 | 顯示目前條件下地圖上共有幾棟建案 |

### 2-3 框選分析分頁

| 功能 | 說明（30 字內） |
|------|------|
| 框選範圍 | 在地圖拖拉矩形，一次把範圍內建案加入分析 |
| 點選加入 | 直接點標記加入或移除，最多同時分析 8 個建案 |
| 搜尋加入 | 用建案名稱搜尋，從清單直接加入分析 |
| 摘要卡 | 顯示選取的建案數、平均單價與總戶數 |
| 類型分布 | 堆疊長條呈現選取建案的房屋類型戶數與占比 |
| 均單價對比 | 長條圖並列比較各選取建案的平均單價 |
| 月度走勢 | 折線圖比較各建案逐月成交均單價變化 |
| 建案明細表 | 列出各案均單價、均總價、戶數，可移除單一建案 |
| 選取分享 | 選取的建案寫進網址，連結可直接還原這組分析 |

## 三、數據分析（`/analysis`）

| 功能 | 說明（30 字內） |
|------|------|
| 多區比較 | 最多同時挑 8 個行政區，並列比較走勢 |
| 指標切換 | 單價、總價、坪數、車位價、交易量、總銷六選一 |
| 統計方式 | 同一指標可看平均、最高或最低值 |
| 時間粒度 | 資料可按月、季、年彙總呈現 |
| 圖表類型 | 折線、長條、點圖三種呈現方式可切換 |
| 期間設定 | 起訖以民國年月自選，範圍 100 年至 120 年 |
| 細部篩選 | 可再限定建物型態、房型、成屋或預售屋 |
| 來源明細 | 滑過資料點可看該點來源交易的建案、地址、日期 |

## 四、住宅價格指數（`/price-index`）

| 功能 | 說明（30 字內） |
|------|------|
| 指數趨勢圖 | 台南住宅價格指數走勢，基期 110 年 1 月 = 100 |
| 數列多選 | 全市、大廈、透天厝與 14 個行政區可勾選比較 |
| 顯示模式 | 一鍵切換看指數值或年增率 YoY% |
| 最新指數卡 | 顯示所選數列的最新一期指數數值 |
| 月增率卡 | 顯示最新一期相較上月的漲跌幅 MoM |
| 年增率卡 | 顯示最新一期相較去年同月的漲跌幅 YoY |
| 距高點卡 | 顯示目前距歷史最高點回落多少，並標出高點時間 |

## 五、市場供給面（`/supply`）

| 功能 | 說明（30 字內） |
|------|------|
| 建照使照趨勢 | 建照與使照核發量走勢，看未來供給與完工交屋節奏 |
| 供需對照 | 核發量疊上實價登錄成交量，比較供給與需求是否平衡 |
| 各區待售新成屋 | 最新一季各行政區待售新成屋（餘屋）數量比較 |
| 全市餘屋趨勢 | 全市待售新成屋逐季變化，看去化壓力升降 |

## 六、建案比較（`/project-compare`）

| 功能 | 說明（30 字內） |
|------|------|
| 產品定位圖 | 以中位單價 × 中位坪數散佈定位各建案產品 |
| 總價等值線 | 圖上虛線代表相同總價，看跨案總價落在哪一級距 |
| 圓圈大小 | 圓圈越大代表該建案成交筆數越多 |
| 建案多選 | 搜尋或勾選建案，最多同時比較數案，可一鍵清除 |
| 預設帶入 | 首次載入自動帶出成交量最大的 6 個建案 |
| 篩選條件 | 可依行政區、建築類型、房型、成/預售縮小範圍 |
| 樣本可靠度 | 成交筆數不足者標為灰點與「樣本不足，僅供參考」 |
| 提醒橫幅 | 選到無成交、樣本不足或跨行政區時主動提醒 |
| 明細表 | 列出各案筆數、中位單價、P25–P75、坪數與期間 |

## 七、建案搜尋（`/search`）

| 功能 | 說明（30 字內） |
|------|------|
| 建案搜尋框 | 輸入名稱即時比對全市預售建案，下拉選取 |
| 建案摘要 | 成交筆數、中位單價、中位坪數、中位總價、成交期間 |
| 位置地圖 | 顯示該建案座標位置，無座標時明確提示 |
| 完整明細 | 列出該案所有交易：日期、樓層、坪數、單價、總價 |
| 車位與註記 | 標示車位價格、特殊關係交易與增建情形 |
| 樣本提醒 | 成交筆數過低時標註中位數不宜當作行情 |
| 連結分享 | 選定建案會寫入網址，連結可直接開到同一建案 |

> 目前僅收錄預售建案，成屋建案搜尋為第二階段功能。

## 九、閱讀資料前要知道的事

| 事項 | 說明（30 字內） |
|------|------|
| 特殊關係交易 | 親友或關係人交易價格易偏離行情，已標註可排除 |
| 中位數統計 | 建案比較與搜尋採中位數，樣本太少時不代表行情 |
| 座標精度 | 部分點位為路段中心而非門牌精確位置 |
| 資料更新 | 每月 1、11、21 日抓實價登錄，3 日抓公會供給資料 |
| 免責 | 資料僅供參考，不構成任何投資建議 |
