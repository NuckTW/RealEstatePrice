# 台南市不動產分析 — 使用說明書

**線上網址**：https://tainan-realestate-ai.vercel.app

**資料範圍**：民國 110 年至今的實價登錄交易（導覽列左上顯示「實價登錄至 XXX 年 X 月」）

> 說明體例：每項功能以 30 字內說明「它做什麼」。
> 2026-11 改版：導覽從 8 項收成 4 項（行情地圖、市場、建案、客群）＋ AI 問答抽屜。

---

## 一、全站共用

| 功能 | 說明（30 字內） |
|------|------|
| 導覽列 | 四個頁面：行情地圖、市場、建案、客群 |
| 篩選列 | 行情地圖、市場、建案三頁共用，切頁時保留條件 |
| 期間快捷 | 近 12 個月、去年 1 月至今、近 3 年、110 年至今或自訂 |
| 區域 | 行政區多選與重劃區／生活圈，不選代表全市 |
| 成屋／預售 | 預設只看預售屋，可切成屋或兩者合看 |
| 更多篩選 | 房型與屋齡（屋齡只適用成屋） |
| 即時套用 | 改任何條件立即更新，不需按套用 |
| 網址分享 | 篩選條件寫進網址，複製連結給別人會看到同畫面 |
| AI 問答 | 右上按鈕開抽屜，自然語言查詢並畫圖（限內部，需密碼） |
| 設定 | 右上齒輪：字級（小／中／大）與明暗主題 |
| 手機版 | 底部 tab bar 換頁，篩選收成一顆按鈕開 sheet |
| 舊網址 | 改版前的頁面網址會自動導到新位置 |

## 二、行情地圖（首頁 `/`）

左地圖、右情報欄的工作台；整頁不捲動，兩欄各自捲動。手機版情報欄是可拉動的底部抽屜。

| 功能 | 說明（30 字內） |
|------|------|
| 群集 | 圓內上排是中位單價、下排是建案數，顏色依單價 |
| 色階 | 赤陶色越深越貴；範圍取 p5–p95，避免極端值壓扁 |
| 預售／成屋 | 預售為實心標記、成屋為空心標記 |
| 路段膠囊 | 同一路段代表點有多個案時合併顯示「N 案」 |
| 位置精度 | 座標為路名級，同一條路共用一點，不是建案精確位置 |
| 價格熱力 | 只畫預售屋，依各案單價上色 |
| 搜尋 | 地圖左上輸入建案或地址，選取後飛到該點 |
| 視野摘要 | 右欄預設顯示目前地圖範圍內的 KPI 與建案排行 |
| 點群集／膠囊 | 右欄列出其中的建案，滑過清單會在地圖上標示 |
| 點建案 | 右欄直接顯示完整交易明細，可加入建案比較 |
| 框選 | 在地圖上拖曳畫範圍，統計範圍內建案並可多案比較 |
| 落點 | 點地圖選中心，半徑 800m～2km 可切換 |
| 量價走勢 | 依目前篩選條件的月成交筆數與中位單價 |

## 三、市場（`/market`）

單頁四段，上方錨點列可直接跳段。

### 3-1 概況

| 功能 | 說明（30 字內） |
|------|------|
| KPI 卡片 | 成交戶數、中位單價／坪數／總價／車位價、總銷售額 |
| 口徑 | 預設中位數，小字標示 n 與平均數 |
| 補登警示 | 迄月太近時提示最近兩個月仍在補登，戶數會低估 |
| 量價走勢 | 月成交筆數與中位單價，補登中月份以斜線標示 |
| 分布統計 | 行政區、建物類型、房型三表切換，可排序 |
| 逐筆明細 | 每筆交易的日期、樓層、坪數、單價、總價與註記 |
| 交易註記 | 標示特殊關係交易、增建、含車位，判讀價格是否失真 |

### 3-2 趨勢比較

| 功能 | 說明（30 字內） |
|------|------|
| 起始條件 | 以篩選列的期間、行政區、成預售為起點 |
| 指標 | 單價、總價、面積、車位價、交易量、成交額 |
| 統計方式 | 平均、最高、最低（最高最低會標出是哪一筆） |
| 時間粒度 | 月、季、年 |
| 行政區 | 最多 6 區並列；未選時自動取交易量前 5 名 |
| 補登期 | 尾端補登中的期間以斜線底標示 |
| 記錄與匯出 | 可存下比較結果、匯出 PNG |

### 3-3 價格指數

| 功能 | 說明（30 字內） |
|------|------|
| 指數卡片 | 最新指數、月增率、年增率、距歷史高點 |
| 範圍切換 | 全市、建物型態或各行政區 |
| 顯示模式 | 指數值或年增率 |

### 3-4 供給

| 功能 | 說明（30 字內） |
|------|------|
| 供需對照 | 建照、使照核發量疊上實價登錄成交量 |
| 缺資料月份 | 114/12 公會來源全為 0，視為缺資料不畫 |
| 待售新成屋 | 各行政區最新一季與全市趨勢 |

## 四、建案（`/projects`）

| 功能 | 說明（30 字內） |
|------|------|
| 建案表 | 各案完整銷售期的中位數，不受篩選列期間影響 |
| 排序 | 點欄位標題排序：成交數、單價、坪數、總價、最新成交 |
| 搜尋 | 依建案名稱或行政區即時篩選 |
| 單價區間 | 淺色帶為 P25–P75，深色刻度為中位數 |
| 樣本少 | 成交少於 10 筆標示「樣本少」，中位數僅供參考 |
| 比較籃 | 勾選最多 8 案，固定在畫面底部 |
| 散佈圖 | 中位坪數 × 中位單價定位產品，虛線為總價等值線 |
| 規格並排 | 行政區、類型、單價、坪數、總價、銷售期間並排 |
| 建案明細 | 點案名看交易明細，可「在地圖上看」 |

## 五、客群（`/potential-buyers`）

| 功能 | 說明（30 字內） |
|------|------|
| 指數地圖 | 村里首購／換新屋／換二手指數與新屋熱度地圖、排行 |
| 自訂指數 | 指數地圖下方的進階區塊，可加資料、調權重 |
| 客源分析 | 選建案或地圖點位，推估潛在買方來自哪些里 |
| 區域輪廓 | 人口與家庭、就業與產業、房市與負擔三段 |
| 重大建設 | 捷運、鐵路地下化、交流道、產業園區、重劃區 |
| 說明抽屜 | 右上「? 說明」：指數算法與資料總覽 |

## 六、閱讀資料前要知道的事

| 事項 | 說明（30 字內） |
|------|------|
| 特殊關係交易 | 親友或關係人交易價格易偏離行情，已標註可排除 |
| 中位數統計 | 全站預設中位數並標 n；樣本太少時不代表行情 |
| 座標精度 | 座標為路名級，同一條路共用一點，非門牌精確位置 |
| 框選範圍 | 精度只到路段，落點半徑 800m 以下不可靠 |
| 補登期 | 最新 2 個月仍在補登，圖上以斜線標示 |
| 資料更新 | 每月 1、11、21 日抓實價登錄，3 日抓公會供給資料 |
| 免責 | 資料僅供參考，不構成任何投資建議 |
